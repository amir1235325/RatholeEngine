# مدیریت مرکزی با پنل وب Hub (Hub Management)

**RatholeHub** یک پنل وب متمرکز تک‌فایلی (Stdlib Python 3 بدون نیاز به `pip`) است که مدیریت ده‌ها سرور ایران و نود خارج را از طریق اتصالات امن SSH آسان می‌کند.

---

## 💻 نحوه اجرای محلی (برای توسعه و تست)

برای اجرای هاب در حالت Mock بدون دست زدن به سرورهای واقعی:
```bash
RATHOLEHUB_MOCK=1 RATHOLEHUB_PORT=8088 python3 rathole-manager/ratholehub/hub.py
```
سپس مرورگر را روی `http://127.0.0.1:8088` باز کنید.

---

## 🔒 معماری امنیت و SSH

هاب هرگز دستورات شل را به‌صورت رشته‌های خام یا String Interpolation روی سرورها اجرا نمی‌کند:
1. دستورات به اکشن‌های شناخته‌شده (Allow-list) نگاشت می‌شوند.
2. تمام آرگومان‌ها با Regexهای سخت‌گیرانه (مانند `RE_NAME`, `RE_IPPORT`, `RE_KEY`) اعتبارسنجی می‌شوند.
3. دستورات به‌صورت آرایه `Argv` جداگانه از طریق SSH اجرا می‌شوند.

---

## ⚡ دکمه «آپدیت همه» (Update All)

با کلیک روی دکمه **«آپدیت همه»** در داشبورد هاب:
- تمام سرورهای ایران و نودها به‌صورت ترتیبی از طریق SSH ارتقا می‌یابند.
- پیشرفت کار روی Progress Bar زنده نمایش داده می‌شود.
- در صورت بروز خطا در هر سرور، عملیات به صورت خودکار رول‌بک می‌شود.
